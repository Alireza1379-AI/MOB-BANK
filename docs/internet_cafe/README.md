# Internet Cafe Management System Blueprint

This folder provides an implementation blueprint for a Flutter Web/Desktop application driven by a Carbon core pricing engine. It covers data models, UI scaffolding, interop glue, and a Carbon CLI that responds to JSON commands.

## Contents
- `flutter_app/lib/` — illustrative Flutter code with a clean folder structure.
- `carbon_core/` — Carbon structs and entrypoint for pricing/reporting.
- `ARCHITECTURE.md` — narrative walkthrough and extension notes.
